## 2. 매장 Temi 이동 및 도착 안내

매장 상품의 구역을 Temi에 저장된 실제 위치명과 연결했다.

| 상품 구역 | Temi 위치명 | 도착 음성 예시 |
|---|---|---|
| 식품 | `식품` | `식품 구역에 도착했습니다.` |
| 생활용품 | `생활용품` | `생활용품 구역에 도착했습니다.` |
| 의류 | `의류` | `의류 구역에 도착했습니다.` |

`OnGoToLocationStatusChangedListener`에서 이동 상태가 `complete`가 된 경우에만 TTS를 실행한다. 안내 후 대기 중인 구역명을 초기화해 같은 음성이 반복되지 않게 했다.

## 3. QR 쇼핑리스트 구역 자동 매칭

외부 QR의 품목에 `section`이 없거나 `unknown`으로 들어와도 상품명을 기준으로 구역을 보정한다.

| 상품명 | 자동 구역 |
|---|---|
| 라면 | 식품 |
| 과자 | 식품 |
| 모자 | 의류 |
| 물티슈 | 생활용품 |
| 샴푸 | 생활용품 |

QR에 `in_stock` 값이 없더라도 위 매칭 상품은 구역이 확인된 재고 상품으로 처리한다. 등록되지 않은 상품은 기존처럼 위치 미지정 또는 재고 없음 상태로 표시한다.

## 4. 픽업 UI 개선

각 재고 상품 카드 오른쪽에 다음 두 버튼을 배치했다.

- `위치 안내`: 해당 구역으로 Temi 이동
- `픽업 완료`: 이동 없이 해당 상품을 완료 처리

같은 구역에 라면과 과자가 함께 있을 때 첫 상품에서만 위치 안내를 사용하고, 같은 구역의 나머지 상품은 바로 픽업 완료할 수 있다.

픽업 완료 후에는 위치 안내 버튼을 제거하고 같은 위치에 비활성 `픽업 완료` 표시를 유지한다. 완료 카드 색상과 상단 진행 수량도 함께 갱신된다.
