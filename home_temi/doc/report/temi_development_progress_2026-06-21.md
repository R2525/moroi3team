## 2. 쇼핑리스트 QR 기능

실제 홈 Temi 앱의 기존 수납, Gemini 사진 분석, 로컬 서버 기능을 유지하면서 홈 화면에 `쇼핑 QR 만들기` 메뉴를 추가했다.

처리 흐름은 다음과 같다.

1. 홈 Temi가 쇼핑리스트 API를 호출한다.
2. 응답의 품목명, 수량, 재고 상태, 매장 구역을 JSON으로 구성한다.
3. 서버 주소나 식별자만 전달하지 않고 쇼핑리스트 전체를 QR 내부에 저장한다.
4. 휴대폰으로 QR을 촬영한 뒤 매장 Temi에 보여준다.
5. 매장 Temi는 별도 서버 연결 없이 QR만으로 쇼핑리스트를 구성할 수 있다.

QR 페이로드 형식은 다음과 같다.

```json
{
  "type": "temi_shopping_list",
  "version": 1,
  "transfer_id": 5,
  "items": [
    {
      "item_name": "라면",
      "quantity": 1,
      "in_stock": true,
      "section": "Food Zone 1"
    }
  ]
}
```

QR 화면을 다시 열 때 API에서 최신 목록을 조회해 QR을 새로 생성한다. QR 화면이 열린 상태에서 자동 갱신되지는 않는다.

## 3. 한글 인코딩 수정

QR에서 한글 물품명이 `??`로 표시되던 문제를 수정했다. ZXing 생성 옵션에 다음 UTF-8 문자셋 힌트를 명시했다.

```java
hints.put(EncodeHintType.CHARACTER_SET, "UTF-8");
```

이 설정으로 한글 품목명이 QR에 손실 없이 저장된다. 수정 전 생성하거나 휴대폰에 촬영해 둔 QR은 다시 촬영해야 한다.

## 4. 테스트 쇼핑리스트

QR 전달 테스트에 사용한 목록은 다음과 같다.

| 품목 | 수량 | 매장 DB 상태 |
|---|---:|---|
| 라면 | 1 | 재고 및 구역 정보 있음 |
| 샴푸 | 1 | 재고 및 구역 정보 있음 |
| 마우스 | 1 | 매장 재고·위치 정보 없음 |
| 지갑 | 1 | 매장 재고·위치 정보 없음 |

마우스와 지갑은 쇼핑리스트에는 포함되지만 매장 DB에 재고·위치 매핑이 없어 매장 앱에서 재고 없음으로 표시될 수 있다.

## 6. 현재 설정과 제약

- 쇼핑 매장 ID: `1`
- 쇼핑 전송 ID: `5`
- 홈 Temi API 후보: `http://127.0.0.1:8000`
- 에뮬레이터 API 후보: `http://10.0.2.2:8000`
- 현재 전송 ID가 코드에 고정돼 있으므로 실제 운영 전 최신 전송을 자동 선택하도록 개선하는 것이 필요하다.
- QR에 목록 전체를 넣는 방식은 서로 다른 네트워크에서도 동작하지만 품목 수가 매우 많으면 QR 밀도가 높아져 인식률이 떨어질 수 있다.
- 매장 Temi가 위치 안내를 수행하려면 QR에 포함된 `section` 정보 또는 매장 DB의 품목·맵 위치 매핑이 정확해야 한다.
